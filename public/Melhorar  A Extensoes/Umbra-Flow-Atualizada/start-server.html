3

Cole este comando no Terminal:

cd "$(find /Volumes ~ -name 'ff-robust-server' -type d 2>/dev/null | head -1)" && python3 server.py
O que este comando faz: Encontra automaticamente a pasta ff-robust-server em qualquer disco e inicia o servidor.

for /r C:\ %i in (ff-robust-server) do @if exist "%i\server.py" (cd /d "%i" && python server.py)
